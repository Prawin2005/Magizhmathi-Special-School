# ANNAI – INTEGRATED CHILD DEVELOPMENT CENTRE
## Complete Website Implementation Plan

**Project Location:** Woraiyur, Tiruchirappalli, Tamil Nadu

**Brand Identity:** ANNAI – Integrated Child Development Centre

**Associated Identity:** Magizhmathi Special School – An initiative of ANNAI Charitable Trust.

**Brand Tagline:** Every Child Deserves a Chance to Shine.

---

# 1. PROJECT OBJECTIVE

Develop a premium, modern, professional and fully responsive website for ANNAI – Integrated Child Development Centre.

The website should position ANNAI as a trusted child development organisation offering rehabilitation, early intervention, therapy and special education.

The website must communicate:

- Trust and compassion.
- Professional care.
- Child development and individual attention.
- Inclusive education.
- Parent engagement.
- A welcoming and supportive environment.

This must be a fully functional website, not just a static design.

# 2. BRAND IDENTITY AND DESIGN SYSTEM

## Colour Palette

Use a White + Blue colour combination inspired by the supplied Magizhmathi logo.

| Colour | Hex Code | Usage |
|---|---|---|
| Royal Blue | #244A87 | Primary brand colour |
| Sky Blue | #078BC5 | Secondary colour |
| White | #FFFFFF | Main background |
| Ice Blue | #EFF6FC | Section backgrounds |
| Light Grey | #E8EDF5 | Borders and dividers |
| Soft Gold | #D9A441 | Small accent details |

### Colour Distribution

- White: 55%
- Ice Blue: 25%
- Royal Blue: 15%
- Sky Blue: 4%
- Soft Gold: 1%

### Logo Guidelines

- Use the original logo provided by the user.
- Do not modify its colours, proportions or design.
- Preserve the original aspect ratio.
- Display the logo in the navbar and footer.
- Use the ANNAI identity as the primary website identity.
- Present Magizhmathi Special School within the Special School section.

### Typography

- Headings: Poppins.
- Body text: Nunito.
- Use clear font hierarchy.
- Maintain excellent readability across desktop and mobile.

### Design Style

- Premium healthcare website aesthetic.
- Clean white backgrounds.
- Large professional photographs.
- Modern editorial layouts.
- Generous whitespace.
- Rounded image corners.
- Elegant buttons.
- Subtle shadows.
- Smooth animations.
- Child-friendly illustrations used sparingly.

Avoid excessive cartoon illustrations, crowded layouts and repetitive card designs.

# 6. BACKEND FUNCTIONALITY

Build a proper FastAPI backend.

Required API modules:

### Enquiry API
- Submit enquiry.
- Validate form data.
- Store enquiry in database.
- Retrieve enquiries for authorised admins.
- Update enquiry status.

### Appointment API
- Submit appointment request.
- Validate date and time.
- Store appointment details.
- Allow admins to manage requests.

Appointment requests must not automatically be treated as confirmed bookings.

### Gallery API
- Upload images.
- Retrieve published gallery items.
- Update gallery information.
- Delete gallery items.
- Manage publication status.

### Content API
- Retrieve services.
- Retrieve facilities.
- Retrieve testimonials.
- Allow authorised admins to update content.
