# ANNAI – Integrated Child Development Centre
## Official Website & Magizhmathi Special School Platform

**Brand Tagline:** *Every Child Deserves a Chance to Shine.*  
**Location:** Woraiyur, Tiruchirappalli, Tamil Nadu, India.  
**Associated Entity:** Magizhmathi Special School – An initiative of ANNAI Charitable Trust.

---

## 🌟 Overview

A modern, responsive, and clinical-grade web platform for **ANNAI Integrated Child Development Centre**, dedicated to pediatric rehabilitation, multidisciplinary therapies, early intervention, and inclusive special education.

### ✨ Key Features Implemented (Phase 1 & Phase 2)

1. **Design System & Branding:**
   - **Colors:** Royal Blue (`#244A87`), Sky Blue (`#078BC5`), White (`#FFFFFF`), Ice Blue (`#EFF6FC`), Light Grey (`#E8EDF5`), Soft Gold (`#D9A441`).
   - **Typography:** Poppins (Headings) + Nunito (Body text).
   - Responsive navbar with sticky glassmorphism, mobile menu drawer, and top informational banner.
   - Professional healthcare footer with service links, contact details, and admin portal access.

2. **Core Website Sections:**
   - **Home (`/`):** Hero headline, statistics, organisation profile, 6 therapy previews, "Why Choose ANNAI", Magizhmathi Special School spotlight, facilities preview, parent reflections, and gallery preview.
   - **About Us (`/about`):** Profile, Vision, Mission, Core Values, and Holistic Developmental Approach.
   - **Our Services (`/services`):** Dedicated sections for all 6 core therapies:
     1. Occupational Therapy
     2. Speech & Language Therapy
     3. Physiotherapy & Motor Rehabilitation
     4. Sensory Integration Therapy
     5. Behavioural Intervention
     6. Early Intervention
   - **Special School (`/special-school`):** Magizhmathi Special School showcase, IEP pathways, life skills, daily routine schedule, and admissions consultation.
   - **Facilities (`/facilities`):** OT unit, speech suites, physio space, sensory integration chamber, special classrooms, and indoor play area with child-safety protocols.
   - **Gallery (`/gallery`):** Category filter tabs, responsive masonry grid, full-screen lightbox modal with keyboard/swipe navigation, and child privacy compliance note.
   - **Contact Us (`/contact`):** Verified location details (Woraiyur, Tiruchirappalli), telephone placeholder, interactive Google Map, direct WhatsApp link, and online enquiry form.
   - **Interactive Modals:** "Make an Enquiry" and "Request Appointment" with full Zod validation and local state persistence.
   - **Floating WhatsApp Button:** Fixed bottom-right with pre-filled message support.
   - **Admin Portal (`/admin`):** Protected dashboard to manage incoming parent enquiries, appointment slots, and gallery uploads.

---

## 🛠️ Technology Stack

- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, React Router DOM, Framer Motion, Lucide React, React Hook Form, Zod.
- **Backend (Upcoming in Phase 3):** Python, FastAPI, Pydantic, Supabase PostgreSQL, Supabase Storage.

## 🚀 Running the Project Locally

### Prerequisites
- Node.js (v18+)
- npm

### Setup
```bash
# Navigate to frontend
cd frontend

# Install dependencies
npm install

# Run Vite dev server
npm run dev
```

Visit `http://localhost:3000` to explore the website.
Visit `http://localhost:3000/admin` to access the Admin Portal.
